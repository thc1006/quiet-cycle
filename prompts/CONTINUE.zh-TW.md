# 接續 Quiet Cycle 0.3.0

先讀 README.md 的實作公式、docs/TRAINING.md、docs/EVIDENCE_REVIEW.md、
docs/TEST_REPORT.md、docs/REVIEW.md，再查看 learning/ 程式。不要建立前端。

先重跑已存在的檢查。將通過、失敗、環境阻擋分列，不可把 CI 設定檔當成 CI 成功。
優先補足靜態型別、Ruff、標準 build、完整相依解析及多平台執行，不能弱化規則換取通過。

模型面：使用獲授權、具正確知識時間的觀察資料，事先固定目標、預測時點、分割與評估。
保留右設限與所有不合格案例的數量；不能只報容易預測的子集。新資料集的校準和測試
不得参与選模。變更特徵後修改 schema/model identity 及 README 公式。

不得宣稱整合所有論文、全球最強或沒有不確定性。不得用合成 benchmark 的好成績作
真人準確度證明，也不得在測試訊號反轉時偷偷改生成器。校準區間有假設，無界必須保留。

只有在使用者提供並授權資料後，才能處理真實健康資料。不要將資料放入 issue、CI
或外部模型提示。任何公開部署、PyPI 發布、GitHub push 或資料分享需另行明確授權。

輸出：可重現命令、檔案與行號、實際差異、新增回歸測試、公式是否仍吻合、剩餘限制。
