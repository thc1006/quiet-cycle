# 獨立審查

以目前 repo 與可重現測試為準，不信任前一份摘要的「通過」。逐項追查：

1. cutoff 是否真的限制原始事件、補登、版本、特徵、訓練標籤與模型資料可用時間。
2. 同一週期或同一人在不同分割的規則，校準/測試是否洩漏至標準化、選模或權重。
3. README 每個公式是否與 Fraction 實作一致，包含量化、截距不正則化、blend、floor、
   rounding、calibration 的 n+1 與 infinity atom、有限區間的日期邊界。
4. direct Landmark、SDK、CLI、HTTP 是否遵守相同的暫停與適用範圍檢查。
5. 缺失、明確無症狀、stream 混用、右設限、修正起點與不合格案例是否被誠實處理。
6. wheel 安裝後是否仍包含型別與契約、是否意外依賴原始碼目錄或前端。
7. clinical claims 是否超出真人證據；hash 是否被錯稱匿名；模型是否可遭 untrusted 輸入替換。

每個問題提供最小反例、精確檔案/行號、影響、修正與測試。不以文風猜測 bug；
不以「數學很複雜」認定更準；不以測試全綠保證沒有問題。保留測試失敗與改善前後證據。
