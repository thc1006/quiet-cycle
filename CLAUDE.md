# Quiet Cycle development

Python library, not a frontend. Read README for the implemented mathematics,
`docs/TRAINING.md` for temporal partitions, and `docs/TEST_REPORT.md` for the actual
release evidence. Source is under `src/quietcycle`.

The new learner is in `learning/`; the historical predictor and duration extension
remain separate. Never describe synthetic results as clinical accuracy, a nominal
interval as a universal guarantee, or imports as a trained wearable model.

Run pytest, contracts, benchmark, mutation checks and installed-artifact checks.
Run mypy/Ruff/build when available; record an unavailable tool as unavailable.
Keep timestamps, explicit negative evidence, right censoring, infinity calibration
atom, missing flags and exact normal-equation checks intact. Do not tune on test.
Do not upload records, publish packages or deploy services without explicit
permission. `prompts/CONTINUE.zh-TW.md` contains the next concrete work items.
